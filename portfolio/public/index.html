Applied AI and ML engineer and forward-deployed engineer (FDE), based in Ontario, Canada.

Most of my work starts with a business problem and a pile of data. I work with the people who have the problem to pin down what they need to decide or automate, then do the rest: clean the data, build the model or agent, check that it actually helps, and ship it in a form they can use.

  • ircc-forecasting/

    2024–25 · capstoneImmigration forecasting for IRCC. 2M+ records, 85%+ accuracy.

    I wrote the Python ETL that took the raw records down to clean time series (99.5% data quality), then compared Prophet, ARIMA and exponential smoothing across 15+ categories and several forecast horizons.

    python prophet arima pandas

  • bogdai/

    2026 · hackathonSix agents that review a contract and write a cited risk report.

    Team entry for the Microsoft Agents League hackathon. Each agent does one step (intake, clause extraction, grounding, risk reasoning, verification, reporting) and hands off to the next. Every risk in the report cites its clause, and high-risk items get flagged for a person to check. Synthetic contracts only.

    microsoft-foundry pydantic python

  • compliance-agent/

    agent projectFinds compliance gaps and turns them into Jira tickets.

    A multi-agent RAG system in LangGraph. It retrieves the relevant regulations, reasons over how the internal process actually works, flags the gaps, and creates or updates Jira tickets, so legal requirements become engineering work.

    langgraph rag multi-agent jira

  • churn-agent/

    agent projectPredicts churn, then drafts retention actions with an LLM.

    The churn model combines transaction features with BERT sentiment signals and reached 85% AUC. A LangChain agent running Mistral then turns the model's output into targeted retention actions.

    It grew out of an earlier churn study that proposed a RAG workflow for retention; that study is the linked repository.

    langchain mistral bert xgboost

  • cse-threat-classifier/

    capstone · CSE CanadaMalware classification on 8M+ records, shipped as a Windows CLI.

    The classes were very uneven. We tried logistic regression, random forest, XGBoost and LightGBM, and the imbalance held LightGBM to 63%, which is the number we reported. The CLI handles 10k+ files an hour.

    lightgbm xgboost scikit-learn

  • scenesense/

    side projectFinds the objects in a photo, describes the scene, and can read it aloud.

    Object detection with DETR and a short scene description, with optional audio in more than one language. Runs as a Gradio app.

    hugging-face detr gradio
